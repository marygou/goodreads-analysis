# 📚 Book Rating Analysis

Exploratory data analysis of my personal Goodreads reading history using **Python, Pandas and Matplotlib**.

The goal of this project is to explore my reading habits, understand the structure and quality of my Goodreads data, and investigate patterns in the books I read and the ratings I give them.

> 🚧 **Project status:** In progress

---

## 🎯 Goals

This project is part of my **Data Science Journey**, where each experiments focuses on developing a new practical skill.

The main goals of this project are to:

* Learn how to work with a real-world dataset using Pandas
* Explore and clean personal data
* Analyse reading habits over time
* Investigate patterns in my book ratings
* Practice data visualization with Matplotlib
* Develop the ability to formulate questions and answer them using data

---

## 📊 Dataset

The dataset comes from my personal **Goodreads Library Export**.

Each row represents a book in my Goodreads library, with information such as:

* Book title
* Author
* My rating
* Average Goodreads rating
* Number of pages
* Date read
* Publication year
* Genres and other book metadata

The original dataset is **not included in this repository** because it contains personal reading history.

---

## 🔎 Questions

The analysis will investigate questions such as:

1. How many books are in my Goodreads library?
2. How many books did I read each year?
3. What is my average book rating?
4. Which genres do I read the most?
5. Which genres receive the highest ratings from me?
6. Is there a relationship between the number of pages and the rating I give a book?
7. How has my average rating changed over time?
